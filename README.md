# Mathematics-tester
A dynamic Tkinter-based math testing application that generates randomized, grade-specific questions across multiple topics, tracks performance, visualizes problems, and provides detailed review and scoring for an interactive learning experience.

✦ CDY Math Tester ✦

CDY Math Tester is an interactive desktop application built with Python and Tkinter that helps students practice math through dynamically generated quizzes tailored by grade level and difficulty.

🚀 Features
Adaptive Question Generation
Arithmetic, algebra, geometry, word problems, graphing, and transformations
Grade-Based Difficulty Scaling
Supports Grade 1–8 with age-appropriate problems
Multiple Difficulty Levels
Easy, Medium, Hard modes
Visual Learning
Canvas renders shapes, graphs, and geometry problems
Randomized Exams
Each session generates 8–20 unique questions
Instant Feedback
Correct/incorrect responses shown immediately
Detailed Review System
Full breakdown of answers before final grading
Score Tracking
Displays final performance summary
🖥️ Technologies Used
Python 3
Tkinter (GUI)
Random, Math libraries
▶️ How to Run
Install Python (3.x recommended)
Save the script as math_tester.py

Run:

python math_tester.py
🎮 How It Works
Enter your name
Select grade level and difficulty
Complete the generated quiz
Review your answers
View final score and performance
